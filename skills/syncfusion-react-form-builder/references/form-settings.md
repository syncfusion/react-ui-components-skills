# Form Settings Panel

The Form Settings Panel appears in the right pane when no field is selected on the React Form Builder canvas. It configures settings that apply to the entire form.

## Properties

- **Title** sets the form name used for export and preview submissions. The default is `Untitled Form`.
- **Width** controls the form width with a CSS value such as `100%`, `500px`, or `80vw`. The default is `500px`.

## Layout settings

- **Hide Label** hides labels for all fields unless an individual field overrides the setting.
- **Size** applies `Default`, `Small`, or `Bigger` sizing to the form controls.
- **Float Label Type** accepts `Never`, `Always`, or `Auto` to control how supported field labels float.

Changes are reflected immediately on the design canvas. Individual field settings remain unchanged when they have their own values.
